# Code of conduct

The `hx` community aims to be open, useful, and safe for everyone.

## Expected behavior

- Be respectful and use professional language.
- Discuss ideas and code, not a person's identity or character.
- Give clear, useful feedback and accept correction.
- Protect private information and ask before sharing it.

## Unacceptable behavior

- Harassment, threats, discrimination, or personal attacks.
- Sexualised or hateful language or imagery.
- Trolling, doxxing, or publishing private information.
- Deliberate disruption of project spaces or services.

## Enforcement

The current maintainer, [@ttaatoo](https://github.com/ttaatoo), is the sole
code-of-conduct decision-maker for this project. For GitHub-hosted content, use
GitHub's [Report content process](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
For project follow-up, open an issue with no sensitive details and ask for a
follow-up path. Do not include the concern's details in a public issue or pull
request.

The maintainer will review reports as soon as practical and will protect the
reporter's privacy. Possible actions include a private warning, removal of
content, a temporary restriction, or a permanent ban. The maintainer may close
or lock a discussion that cannot remain constructive.

GitHub's [Community Guidelines](https://docs.github.com/en/site-policy/github-terms/github-community-guidelines)
also apply to GitHub-hosted project spaces.
